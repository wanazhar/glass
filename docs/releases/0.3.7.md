# Glass 0.3.7

Glass 0.3.7 was an exact-tag candidate for the complete issue #36 product
repair. Windows CI exposed an unsynchronized native daemon integration fixture,
so this version was not published and has been superseded by 0.3.11.

## Major features

- One canonical revision-safe BrowserWorkspace serves standalone Browser and
  embedded App TUIs with semantic selection, workflows, recovery, Herdr, and
  explicit tokenized loopback Remote View.
- Glass Agent has managed Pi readiness/setup, direct conversation, session
  controls, browser context, confirmation, and human-takeover reconciliation.
- The rebuilt desktop and phone workspaces provide real Code editing, App
  interaction, Git/runtime/task projections, local focus/scroll/input, fuzzy
  command completion, and bounded history.
- Daemon long work uses stable operation IDs, bounded events, reconnect-safe
  inspection, cancellation, and reconciliation; Agent workers are always joined.
- Task success uses inferred deterministic project verification unless the user
  explicitly requests settlement-only completion.

## Breaking changes

There are no intentional Rust, MCP, CLI, profile, or workspace-storage removals.
Daemon clients should consume stable operation identities instead of inferring
mutation outcomes from a fixed client timeout. The Development TUI information
architecture now prioritizes work destinations over equal-weight subsystems.

## Security

Semantic actions carry the visible revision and stale targets fail closed.
Human takeover suspends Glass mutation ownership until reconciliation. Remote
View is loopback-only, random-token protected, bounded, newest-frame only,
revision checked, and explicitly revocable. Pi setup is explicit and credentials
or provider secrets are never logged.

## Installation and migration

This failed candidate was not published. Install the corrected release with:

```console
cargo install glass-dev --version 0.3.12 --locked --force
```

Library users select `glass-browser = "0.3.12"`. See
[the current migration guide](../migration/0.3.12.md).

## Known limitations

- Chrome/Chromium remains the only automation backend.
- Native browser, graphics, PTY, and debugger certification is platform-specific.
- Remote View deliberately requires loopback or SSH forwarding.
- The signed 0.3.6 tag is audit evidence only and was never a registry release.
- The signed 0.3.7 tag is also audit evidence only and was never a registry
  release.
