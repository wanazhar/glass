# Extraction and pagination revision safety

## Delivered

- Table, collection, and region extraction now reject results observed from a
  different revision or route than the caller's scoped preflight observation.
- `pagination.collect` compares semantic page and region content while ignoring
  revision-scoped target handles, so no-op controls stop after one verified
  attempt instead of replaying side effects until the action bound.
- Pagination now reports a bounded limit only when semantic progress remains
  possible through the configured action/item budget.

## Verification

- Fixture-backed Linux ARM64 smoke coverage confirms a static next control is
  attempted once and the collection trace contains only observe plus one click.
- Full Rust, lint, documentation, package, and release metadata checks remain
  required before publication approval.
