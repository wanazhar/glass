# Objective

Distinguish validated relationship hints that emit an edge from valid hints
whose parent entity is not observed.

# Contract

- `emitted` means the validated hint resolved to an observed parent and added a
  relationship edge.
- `unmatchedParent` means validation passed but no observed parent matched the
  bounded role.
- Unmatched hints never create entities or relationships and remain
  non-actionable.
- Diagnostics retain original evidence fact ordering.
- Invalid source or parent-role hints still fail before reconciliation.

# Verification

- matched and unmatched diagnostic status tests;
- `cargo test --all-targets --locked`;
- `cargo clippy --all-targets --all-features --locked -- -D warnings`;
- `cargo fmt --all -- --check`;
- fixture corpus validation.
