# Objective

Expose validated relationship-hint outcomes on successful draft Web IR output
without weakening failure-before-reconciliation validation.

# Contract

- Valid hints produce typed diagnostics containing only fact index, source,
  bounded hint, parent role, and `validated` status.
- Invalid hints still fail before a draft is returned.
- Drafts without hints retain an empty diagnostic list.
- Diagnostic ordering follows original evidence fact order.
- Diagnostics contain no selectors, node IDs, URLs, credentials, or values.

# Verification

- typed diagnostic serialization tests;
- invalid-hint rejection remains covered;
- `cargo test --all-targets --locked`;
- `cargo clippy --all-targets --all-features --locked -- -D warnings`;
- `cargo fmt --all -- --check`;
- fixture corpus validation.
