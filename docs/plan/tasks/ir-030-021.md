# Objective

Expose Task Protocol compilation through the transport-neutral Glass request
boundary without coupling request parsing to browser execution.

# Contract

- `task.compile` is a typed operation payload carrying one validated authored
  task.
- The payload preserves strict Task Protocol unknown-field rejection.
- Request decoding checks the operation name and task validation before a
  compiler is called.
- No browser session, mutation lease, selector, or CDP data is required.

# Verification

- valid task.compile requests decode deterministically;
- wrong operation, malformed payload, unknown fields, and invalid tasks fail
  at the request boundary;
- all-targets tests excluding the known stale daemon test, clippy, formatting,
  and documentation checks.
