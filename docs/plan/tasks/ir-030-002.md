# Objective

Define the strict authored request boundary for bounded browser evidence
extraction without implementing browser mutation or a stable Web IR result.

# Context

- `issue://wanazhar/glass/30`
- `docs/plan/analysis/semantic-execution-030.md`
- `docs/ownership.md`

# Path

- `src/extraction.rs`
- `src/lib.rs`
- `tests/web_ir_corpus.rs`
- `docs/ownership.md`

# Contract

`ExtractionRequest` must validate:

- schema version;
- document, region, or frame scope;
- one or more unique evidence sources;
- positive bounded node, text, depth, duration, and output limits;
- strict authored JSON fields;
- identifiers without control characters or unbounded length.

The contract is non-mutating and contains no CSS selectors, XPath, CDP node
IDs, raw DOM, credentials, or page content. It is an experimental request
boundary; evidence output and stable Web IR serialization are later pillars.
