# Historical 0.3.6 migration candidate

The 0.3.6 package was not published. Use the current migration guide instead
of installing this historical candidate:

```console
cargo install glass-dev --version 0.3.12 --locked --force
```

Library users should set `glass-browser = "0.3.12"`; the full package retains
the exact dependency `glass-browser =0.3.12`.

## Product changes

- `glass` opens the rebuilt Agent-first Development Workspace; use `Tab` or
  direct number keys to move among the responsive destinations.
- App and `glass-browser tui` now share semantic selection and revision-safe
  controls. Press `n` for address entry, `t` to type into the selected target,
  Enter to activate it, and Page Up/Down to scroll the live page.
- The command palette supports fuzzy completion with Tab and bounded history
  with Up/Down. Mutating palette tools freeze until one explicit approval.
- First-run Agent setup is explicit: `glass agent doctor`, `glass agent setup`,
  and `glass agent status`; from the TUI use `:agent setup [login]`.

## Automation changes

- Long daemon mutations use `operation.submit`, `operation.inspect`,
  `operation.events`, `operation.cancel`, and `operation.reconcile`. Do not rely
  on a fixed client timeout to infer whether a mutation occurred.
- Default task verification is project-inferred. Request `Settled` only when
  acknowledgement without a deterministic verifier is intentional.
- Human browser takeover invalidates the previous mutation lease. Reconcile the
  current revision before returning control to Glass.

No migration exports secrets, screenshots, DOM, cookies, or prompt content.
