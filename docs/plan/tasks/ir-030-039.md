# ir-030-039

Status: complete

## Objective

Expose browser-free Web IR inspection and validation through canonical Glass
protocol operations shared by MCP and embedded Rust callers.

## Contract

- `webIr.inspect` and `webIr.validate` carry one validated `GlassWebIrDraft`
  under `draft`.
- Inspection returns bounded `WebIrInspectionResult` metadata.
- Validation returns bounded `WebIrValidationResult` metadata.
- MCP `inspectWebIr` and `validateWebIr` map to these operation names without
  starting Chrome or acquiring a mutation lease.
- Unknown fields and mismatched operation payloads remain rejected.

## Evidence

- Canonical request and response helpers are implemented in `glass::protocol`.
- MCP canonical mapping coverage exercises both tool names.
- Protocol golden coverage includes both operation envelopes.
- Focused protocol and MCP tests pass; full repository checks remain the
  release gate.
