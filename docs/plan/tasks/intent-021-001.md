# Objective

Define one strict, bounded intent-resolution contract before candidate
generation or execution is added.

# Delivered

Added request, result, candidate, evidence, scope, constraint, resolution
policy, confidence, and disambiguation types with canonical camelCase JSON,
route/revision fields, explicit classifications, and bounded validation. The
published schema is `docs/schema/intent-resolution-v1.schema.json`.

No action is dispatched by this contract layer.
