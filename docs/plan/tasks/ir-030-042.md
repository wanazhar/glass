# ir-030-042

Status: complete

## Objective

Ensure browser-free MCP Web IR tools execute through the canonical Glass
protocol boundary while retaining typed validation failures.

## Contract

- `inspectWebIr` and `validateWebIr` construct typed `webIr.inspect` and
  `webIr.validate` requests.
- `diffWebIr` and `continuityWebIr` construct typed `webIr.diff` and
  `webIr.continuity` requests.
- MCP-only response options are excluded from canonical draft payloads.
- Invalid drafts continue to return bounded `webIrValidation` errors with path
  and reason fields.
- No Web IR operation starts Chrome, acquires a mutation lease, or dispatches
  browser actions.

## Evidence

- MCP integration tests cover all four browser-free Web IR tools.
- Canonical boundary coverage proves transport options are excluded and typed
  request decoding succeeds.
- Protocol errors preserve typed Web IR validation failures for MCP projection.
- Full repository validation remains the release gate.
