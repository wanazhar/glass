# Glass 0.3.10

Glass 0.3.10 is the post-0.3.9 hardening release. It keeps the issue #36
product repair intact while making the interactive TUI more responsive,
discoverable, and truthful under background work.

## Major features

- Per-surface action menus and the unified help cockpit make ordinary Agent,
  Code, App, Git, browser, test, debugger, and trust flows discoverable without
  memorizing palette command strings.
- The standalone Browser TUI and embedded App surface retain the canonical
  BrowserWorkspace and now expose live ANSI fallback, responsive status
  feedback, browser recovery choices, and non-blocking semantic navigation.
- Glass Agent conversation, Pi setup, Git, browser recovery, and live capture
  stay on governed background paths so terminal input remains responsive while
  projections hydrate.
- Human-readable projections cover resident browser, agent, workspace, Git,
  tests, debugger, kernels, LSP, workflow, and trust state; raw JSON remains an
  explicit inspect/diagnostic route.
- Phone and compact layouts expose operation status beside navigation hints,
  render the cockpit before background projections, and keep the reduced
  Agent/Code/App/Tasks/More information architecture discoverable.

## Breaking changes

There are no intentional Rust, MCP, CLI, profile, or workspace-storage
removals. The package boundary remains one-way: `glass-dev` depends on the
exact matching `glass-browser` release. Existing daemon clients should continue
to use stable operation identities and reconcile long-running mutations rather
than treating a client timeout as the operation result.

## Security

The issue #36 safety contracts remain unchanged. Browser mutations stay
revision-bound and stale state fails closed. Human takeover, confirmation,
workspace authority, bounded queues, and explicit Pi setup remain enforced.
Live frames stay bounded and are never the primary semantic or agent context;
credentials, cookies, prompt text, and evaluated user input are not logged.

## Installation and migration

Install the full product with:

```console
cargo install glass-dev --version 0.3.10 --locked --force
```

Library users select:

```toml
glass-browser = "0.3.10"
```

The full package retains the exact `glass-browser =0.3.10` dependency. See
[the migration guide](../migration/0.3.10.md) for the focused changes from
0.3.9.

## Known limitations

- Chrome/Chromium remains the only automation backend.
- Native browser, graphics, PTY, and debugger certification is platform-specific.
- Remote View deliberately requires loopback or SSH forwarding.
- TypeScript and Python clients remain repository clients; this release has no
  npm or PyPI artifacts.
