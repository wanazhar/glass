# Historical 0.3.8 migration candidate

Versions 0.3.6 through 0.3.8 were not published. Use the current migration
guide instead of installing this failed candidate:
```console
cargo install glass-dev --version 0.3.11 --locked --force
```

Library users should set `glass-browser = "0.3.11"`; the full package retains
the exact dependency `glass-browser =0.3.11`.

The product and automation changes are the canonical BrowserWorkspace, rebuilt
Agent/Code/App desktop and phone shells, managed Pi lifecycle, stable daemon
operations, inferred verification, revision-bound actions, and explicit human
takeover/reconciliation described in the 0.3.6 candidate guide. The corrected
release also keeps standalone TUI browser startup off the input loop and synchronizes
the Windows named-pipe integration fixture with the recoverable-operation
protocol.

No migration exports secrets, screenshots, DOM, cookies, or prompt content.
