# Verified navigation destinations

## Delivered

- `navigation.follow` now verifies the final browser URL against the requested
  destination after revision-guarded navigation.
- URL fragments are ignored because they are not part of the browser page URL;
  trailing-slash differences are treated as equivalent.
- Redirects and other destination mismatches return `indeterminate` with
  unsafe-until-reconciled recovery guidance.
- Added unit and Linux ARM64 browser smoke coverage for exact destinations and
  redirect mismatches.

Full Rust, lint, documentation, package, and release metadata checks remain
required before publication approval.
