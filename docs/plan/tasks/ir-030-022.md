# Objective

Make compiled Task Protocol plans a typed transport response rather than an
unstructured result blob.

# Contract

- `TaskCompileResult` wraps one validated execution plan.
- Response decoding requires a successful canonical Glass response and validates
  the embedded plan before returning it.
- Typed result JSON round-trips without losing plan metadata or secret input
  values.

# Verification

- compiled plans encode and decode through a canonical response payload;
- malformed, failed, and unknown-field response payloads fail closed;
- all-targets tests excluding the known stale daemon test, clippy, formatting,
  and documentation checks.
