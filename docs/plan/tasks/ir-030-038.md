# Canonical Glass protocol operations for Web IR revision analysis

## Objective

Give browser-free Web IR revision analysis transport-neutral operation names and
typed request/response helpers shared by embedded Rust callers and MCP mapping.

## Contract

- `webIr.diff` carries two validated draft graphs and returns the bounded
  `WebIrDiffResult` summary.
- `webIr.continuity` carries two validated draft graphs plus a bounded source
  entity ID and returns `WebIrContinuityResult`.
- Invalid drafts and malformed IDs fail before analysis or browser access.
- MCP `diffWebIr` and `continuityWebIr` map to these canonical operations while
  retaining their bounded MCP result projections.

## Verification

Protocol unit tests exercise both request decoders and result decoders. The
protocol golden fixture round-trips both operation envelopes, MCP tests verify
canonical operation mapping, and the full repository checks remain required
before the local commit.
