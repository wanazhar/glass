# Objective

Add deterministic revision diff output for the bounded draft Web IR.

# Contract

- Diffing validates both source drafts before comparison.
- Entity changes are keyed by canonical entity ID and sorted deterministically.
- Relationship changes are keyed by `(from, to, kind)` and sorted deterministically.
- Revision numbers, coverage changes, limits changes, diagnostics changes, and
  relationship-hint diagnostic changes are reported explicitly.
- Diffing performs no browser actions and exposes no raw values beyond data
  already present in validated drafts.

# Verification

- draft diff unit tests for additions, removals, changes, and determinism;
- all-targets tests excluding the known stale daemon test;
- clippy, formatting, docs, and corpus validation.
