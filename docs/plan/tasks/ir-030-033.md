# Objective

Expose validated Web IR entity-continuity classification through the offline CLI.

# Contract

- `glass ir continuity BEFORE.json AFTER.json ENTITY_ID` validates both drafts
  and prints the bounded continuity result.
- Output uses the existing `DraftEntityContinuity` contract and never starts
  Chrome or emits input values, selectors, or CDP identifiers.
- Removed, changed, rebound, and ambiguous outcomes remain explicit and
  fail-closed.

# Verification

- CLI parser coverage covers the continuity command.
- CLI dispatch reuses the validated Rust continuity API.
- Formatting, tests, clippy, documentation, and release checks pass.
