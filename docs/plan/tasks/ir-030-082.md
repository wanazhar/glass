# Typed table and collection records

## Objective

Expose bounded, item-level records for semantic table and repeated-collection
extractions without replacing the compatibility `records` envelope.

## Contract

- `table` and `repeatedItems` fields produce `recordItems` only from the
  validated semantic array value.
- Each item carries its authored field name, zero-based bounded index, semantic
  value, and any evidence-backed entity reference.
- Item values are copied only within the existing request bounds; no raw DOM,
  selectors, credentials, or page secrets are introduced.
- Existing `records`, `provenance`, field provenance, and limit metadata remain
  compatible.

## Delivered

- Added `StructuredExtractionRecord` and `recordItems` to the library result.
- Populated item records after max-item truncation for table and collection
  extraction kinds.
- Re-exported the record type through `glass::browser::session`.
- Documented the additive MCP result field.

## Verification

- Unit coverage verifies table item indices, semantic values, entity references,
  and exclusion of non-record kinds.
- Focused extraction and task/MCP interface tests pass.
- Full Rust, formatting, check, Clippy, and repository validation remain
  required before the next release boundary.
