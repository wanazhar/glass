# Objective

Expose strict browser-free Task Protocol validation through MCP alongside the
CLI validation command.

# Contract

- `validateTask` is advertised as a read-only MCP tool.
- Valid tasks return bounded metadata only: validity, schema version, and task kind.
- Input values are never serialized in successful responses.
- Invalid tasks return bounded `taskValidation` errors without starting Chrome.
- Existing `compileTask` behavior and tool compatibility remain unchanged.

# Verification

- MCP advertisement and conformance fixture include `validateTask`.
- Valid and invalid calls are covered without browser startup.
- Formatting, tests, clippy, documentation, and diff checks pass.
