# Canonical browser-backed task dispatcher

## Delivered

- Added `BrowserSession::execute_task` as the shared typed dispatcher for all
  currently supported browser-backed Task Protocol families.
- CLI `glass task execute` and MCP `executeTask` now call the same dispatcher
  instead of maintaining parallel family-routing logic.
- Specialized form, navigation, dialog, and extraction implementations remain
  behind the dispatcher while preserving their existing guarded behavior.

## Verification

- Compiler and task runtime checks pass with the unified routing boundary.
- Linux ARM64 fixture-backed browser smoke exercises extraction through the
  canonical dispatcher alongside navigation, tab, dialog, pagination, and form
  operations.
- Full Rust, lint, documentation, package, and release metadata checks remain
  required before publication approval.
