# Objective

Expose the browser-free extraction and experimental Web IR contracts through
crate-root Rust imports without implying that native browser extraction is
stable.

# Contract

- Extraction request, evidence, and budget types are available from `glass`.
- Draft Web IR, diff, continuity, reconciliation, and validation types are
  available from `glass`.
- Existing module paths remain valid.
- Documentation marks these exports experimental and browser-free.

# Verification

- Crate-root integration coverage compiles and validates a request.
- Full formatting, tests, clippy, documentation, and fixture checks pass.
