# Public verified form task execution

## Objective

Expose the browser-backed verified form Task Protocol runtime through the CLI
and MCP without creating a second execution path.

## Delivered

- `glass task execute TASK.json --expected-revision REVISION [--confirm]`.
- MCP `executeTask` with the same authored task, revision guard, and explicit
  confirmation contract.
- Both interfaces invoke `BrowserSession::execute_form_task` and return the
  bounded execution result without serializing authored input values.
- Form fill and submit postconditions are evaluated against a fresh scoped
  observation after mutation.

## Safety boundary

Only `form.inspect`, `form.fill`, `form.validate`, and `form.submit` execute in
this increment. Unsupported task families return a bounded preflight result;
they are not routed through the form executor. MCP mutation lease enforcement
remains active for `executeTask`.

## Verification

- CLI help smoke test passed.
- MCP parser and tool inventory tests passed.
- Task runtime unit tests passed.
- Linux ARM64 browser fixture for scoped form execution passed.
