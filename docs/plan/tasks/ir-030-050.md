# ir-030-050

Status: complete

## Objective

Align safe offline CLI Web IR projections with the canonical protocol helpers
used by MCP.

## Contract

- `glass ir validate` uses `webIr.validate`.
- `glass ir inspect` uses `webIr.inspect`.
- `glass ir continuity` uses `webIr.continuity`.
- Existing bounded result projections remain unchanged for these commands.
- The detailed local `glass ir diff` output remains available and is not
  replaced by the bounded MCP summary projection.
- No command starts Chrome or performs browser mutation.

## Evidence

- CLI unit coverage constructs each canonical request and dispatches its typed
  result helper, including unchanged continuity.
- CLI smoke coverage validates and inspects browser-free Web IR fixture data.
- Protocol documentation records the shared helper boundary and deliberate diff
  projection distinction.
