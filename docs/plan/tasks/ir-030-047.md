# ir-030-047

Status: complete

## Objective

Make invalid browser-free Task MCP requests return stable typed error details
for agent recovery and debugging.

## Contract

- `validateTask` returns `isError: true` with a bounded `taskValidation` detail.
- `compileTask` returns `isError: true` with a bounded `taskCompilation` detail
  when the authored task cannot be compiled.
- Both details include only the machine-readable `path` and `reason`; input
  values and browser state are not returned.
- Neither invalid request starts Chrome or creates a browser session.

## Evidence

- MCP regression coverage exercises both tools with the same invalid `form.fill`
  request and checks typed details and session absence.
- MCP documentation includes the validation error shape and the compilation
  error example.
