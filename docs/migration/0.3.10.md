# Historical 0.3.10 migration candidate

The signed v0.3.10 candidate failed before registry publication and is retained
as immutable audit evidence. Do not install it. Update directly from the
published 0.3.9 line to 0.3.13:

```console
cargo install glass-dev --version 0.3.13 --locked --force
```

Library users should set `glass-browser = "0.3.13"`; the full package retains
the exact dependency `glass-browser =0.3.13`.

Use [the current 0.3.13 migration guide](0.3.13.md) for the TUI, Agent,
browser, compatibility, and safety changes.
