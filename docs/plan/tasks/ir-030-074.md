# Verified menu-opening outcomes

## Delivered

- `navigation.openMenu` now verifies the clicked control's observable
  `aria-expanded="true"` state after a fresh post-action observation.

  reconciliation guidance; it is never reported as a successful menu opening.
- Moved the menu execution branch behind a bounded helper future to keep the
  large task dispatcher within the browser smoke thread stack budget.
- Added positive and negative Linux ARM64 browser smoke coverage.
