# Objective

Expose deterministic validated Web IR serialization through the offline CLI.

# Contract

- `glass ir canonical DRAFT.json` validates the draft and prints its canonical
  JSON representation to stdout.
- Output reuses `GlassWebIrDraft::to_canonical_json` and does not add CLI
  metadata, input values, selectors, or CDP identifiers.
- Invalid drafts fail before any output is emitted.

# Verification

- CLI parser coverage covers the canonical command.
- CLI smoke coverage confirms deterministic canonical output.
- Formatting, tests, clippy, documentation, and release checks pass.
