# Migrate from 0.3.5 to 0.3.7

Skip the unpublished 0.3.6 tag and update directly:

```console
cargo install glass-dev --version 0.3.7 --locked --force
```

Library users should set `glass-browser = "0.3.7"`; the full package retains
the exact dependency `glass-browser =0.3.7`.

The product and automation changes are the canonical BrowserWorkspace, rebuilt
Agent/Code/App desktop and phone shells, managed Pi lifecycle, stable daemon
operations, inferred verification, revision-bound actions, and explicit human
takeover/reconciliation described in the 0.3.6 candidate guide. Version 0.3.7
also keeps standalone TUI browser startup off the input loop: the workspace
renders immediately, and `navigate`, `launch`, or `attach` starts/connects a
browser on demand.

No migration exports secrets, screenshots, DOM, cookies, or prompt content.
