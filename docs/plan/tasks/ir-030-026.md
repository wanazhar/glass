# Objective

Expose typed authored-task compilation failures through the browser-free MCP
`compileTask` path so clients can correct invalid declarations without starting
Chrome or parsing a generic browser failure.

# Contract

- Validly shaped but invalid Task Protocol tasks return MCP `isError: true`.
- The text content is a bounded JSON object with `kind`, `path`, and `reason`.
- Invalid compilation leaves the browser session unset.
- Existing successful compilation responses remain unchanged.

# Verification

- MCP invalid-task behavior asserts the typed error and browser-free boundary.
- MCP compile documentation describes the failure shape.
- Formatting, tests, clippy, and documentation checks pass.
