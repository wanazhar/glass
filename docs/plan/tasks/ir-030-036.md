# Browser-free MCP Web IR inspection and validation

## Objective

Expose the existing experimental draft Web IR contract through bounded MCP
operations without starting Chrome or acquiring a mutation lease.

## Contract

- `validateWebIr` accepts one draft object, validates graph invariants, and
  returns only `valid`, `schemaVersion`, and `revision` on success.
- `inspectWebIr` validates the same draft and returns bounded summary metadata:
  counts, coverage, truncation, opaque-region count, and diagnostic counts.
- Invalid graphs return typed `webIrValidation` errors with a path and reason.
- Neither operation exposes entity IDs, relationships, page content, or browser
  identifiers in its success response.
- Both operations remain browser-free and are exempt from mutation leases.

## Verification

- MCP server regression tests cover successful bounded inspection, typed invalid
  drafts, browser-session non-start, and tool advertisement.
- MCP protocol conformance covers the expanded tool inventory.
- Existing CLI, Web IR, and MCP behavior remains unchanged outside the new tools.

## Follow-up

This increment exposes draft inspection only. It does not make the draft Web IR
stable, execute tasks, or authorize browser actions.
