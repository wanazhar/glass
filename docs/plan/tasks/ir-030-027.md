# Objective

Make browser-free task compilation inspectable without changing the canonical
plan output consumed by scripts and clients.

# Contract

- `glass task compile TASK.json --explain` emits a deterministic explanation.
- The explanation contains task, semantic scope, risk, confirmation, steps, and
  postcondition metadata, but never input values.
- Without `--explain`, existing JSON output and output-file behavior remain
  unchanged.
- Explanation mode does not start Chrome or execute a plan.

# Verification

- CLI parsing covers `--explain`.
- Smoke execution confirms explanation output and absence of input values.
- Existing CLI and compiler tests remain green.
