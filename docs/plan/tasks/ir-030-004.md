# Objective

Reconcile bounded evidence facts into a deterministic experimental draft Web IR
entity and relationship graph.

- `docs/plan/README.md`

# Contract

The draft graph must:

- preserve source revision and coverage metadata;
- use canonical entity kinds and relationship kinds;
- merge equivalent facts from different evidence sources;
- retain duplicate same-source candidates for later ambiguity handling;
- generate deterministic bounded identifiers without selectors or CDP IDs;
- expose evidence quality and source provenance;
- reject dangling relationships and duplicate IDs;
- fail closed rather than inventing unsupported relationships.

This is an experimental draft and not the stable Web IR v1 contract.
