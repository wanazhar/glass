# Typed dialog inspection payload

## Delivered

- Task execution results now expose an optional bounded `dialog` payload for
  `dialog.inspect`.
- The payload preserves dialog type, bounded message, default prompt value,
  and opener URL through the existing `PendingDialog` contract.
- Dialog action results continue to omit dialog details after successful
  closure and retain the shared recovery shape.

## Verification

- Fixture-backed Linux ARM64 browser smoke opens a confirmation dialog,
  inspects and asserts its typed message, then confirms it through the guarded
  task runtime.
- Full Rust, lint, documentation, package, and release metadata checks remain
  required before publication approval.
