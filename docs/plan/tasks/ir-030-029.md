# Objective

Expose strict browser-free Task Protocol validation as a standalone CLI
operation for local agents and CI checks.

# Contract

- `glass task validate TASK.json` parses and validates authored Task Protocol
  JSON without compiling or starting Chrome.
- Success prints bounded JSON containing `valid`, `schemaVersion`, and `task`.
- Input values are never printed.
- Invalid authored tasks fail before browser startup with the existing typed
  validation error path.

# Verification

- Clap parsing and dispatch are covered.
- A valid task smoke test succeeds without Chrome.
- Formatting, tests, clippy, documentation, and release checks pass.
