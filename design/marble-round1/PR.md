# design: propose Marble iOS identity and home direction

## Summary

- Recommend Pocket Pair, a quiet identity for Marble, with two alternate marks, icon treatments and a short, skippable splash.
- Compare a personality picker and Everyone as home. Show the conversation, memory, activity, settings and connection journey in light and dark on iPhone, with split layouts on iPad.
- Include visual and component sheets, unmodified main captures from a seeded host, and a disposable iOS 26 SwiftUI prototype. No production app or host code changes.

## Review decision

Choose the mark and which home should open first. The recommendation is **Pocket Pair + personality picker**. Begin with the [round review](README.md), then compare [picker home](iphone/picker-light.png) and [Everyone home](iphone/home-everyone-light.png). These are design proposals, not behavior changes.

## Verification
