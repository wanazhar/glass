# Objective

Compile a validated Task Protocol v1 task into a deterministic, browser-free
execution plan.

# Contract

- Compilation validates before producing any plan.
- Plans contain typed operations, stable ordinals, bounded input names only,
  copied risk and postcondition metadata, and an explicit confirmation gate.
- Plan generation has no browser, network, DOM, selector, or CDP dependency.
- Sensitive input values never appear in the plan output.

# Verification

- every supported task family maps to a stable operation sequence;
- plan serialization is deterministic;
- irreversible and confirmation-gated tasks carry an explicit confirmation
  requirement;
- invalid authored tasks fail before a plan is emitted;
- all-targets tests excluding the known stale daemon test, clippy, formatting,
  and documentation checks.
