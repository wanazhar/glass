# Continuation region binding

## Objective

Keep a resumed extraction attached to the same semantic region as the first
bounded slice, even when multiple tables or collections share one page route.

## Contract

- Continuation metadata carries the optional requested region identity.
- A continuation for a scoped extraction cannot be resumed against another
  region or an unscoped request.
- Page-level continuations remain valid with no region identity.
- Revision and route validation remain unchanged and continue to fail closed.

## Delivered

- Added optional region identity to continuation output and input tokens.
- Validated region identity alongside source revision and route.
- Extended MCP schema, documentation, and focused helper coverage.

## Verification

- Continuation and MCP-focused tests pass.
- Full Rust, formatting, check, Clippy, documentation, and browser smoke checks
  remain required before the next release boundary.
