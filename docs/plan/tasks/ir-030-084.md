# Structured record continuity

## Objective

Ensure revision-aware task verification treats semantic table and collection
record changes as observable page changes.

## Contract

- A change to bounded semantic structured records invalidates page-equivalence
  checks used by pagination and post-action verification.
- Identical structured records remain a semantic no-op when all existing page
  and target evidence is unchanged.
- The change is additive and does not alter revision, route, or target identity
  rules.

## Delivered

- Included `structuredRecords` in semantic region change detection used by
  browser-backed task execution.
- Added regression coverage for unchanged and changed structured records.

## Verification

- Focused task and continuity tests pass.
- Full Rust, formatting, check, Clippy, browser smoke, and repository checks
  remain required before the next release boundary.
