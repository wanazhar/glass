# Intent resolution fixture corpus

## Scope

Keep representative intent classifications and policy outcomes deterministic
and reviewable without a live browser.

## Acceptance criteria

- [x] Fixtures cover exact, ambiguous, not-found, stale, report-only, and
      unsupported intent outcomes.
- [x] An offline example validates the expected resolution and policy decision
      for every fixture.
- [x] The corpus remains bounded and contains no browser profile or secret data.

## Validation

```text
cargo run --example intent_scorecard
```
