# Objective

Produce explicit, bounded relationship hints for custom form controls from
strong form ancestry evidence.

# Contract

- Only `checkbox`, `combobox`, and `radio` controls under a bounded `form`
  ancestor receive the `controls` hint.
- The hint is produced only for `EvidenceSource::Forms`, which permits it.
- Text controls and controls without a form ancestor retain no explicit hint.
- No selectors, values, URLs, or node IDs enter the evidence contract.

- extraction unit tests;
- Web IR reconciliation tests;
- all-targets tests excluding the known stale daemon test;
- clippy, formatting, docs, and fixture corpus validation.
