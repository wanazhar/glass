# Objective

Provide browser-free CLI inspection and diff commands for validated Web IR
Draft JSON.

# Contract

- `glass ir inspect DRAFT.json` validates the draft and prints bounded summary metadata.
- `glass ir diff BEFORE.json AFTER.json` validates both drafts and prints the deterministic IR diff.
- Neither command starts Chrome or performs browser work.
- Draft JSON emitted by the Web IR serializer remains readable when optional empty arrays are omitted.

# Verification

- CLI parser coverage covers inspect and diff.
- CLI smoke coverage validates summary and diff output.
- Full formatting, tests, clippy, documentation, corpus, and release checks pass.
