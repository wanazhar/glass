# Native Pi SDK runtime (retired)

**Historical source note.** Glass Dev no longer embeds, installs, selects, or
falls back to the Pi SDK. Resident agents use the standalone Glass Core engine;
see the [Glass Core resident harness](../glass-core-harness.md) for current setup
and provider ownership. Pi-specific setup commands, runtime assets, and session
adapters have been removed from Glass.

Older Glass releases included a managed Pi `AgentSession` integration. Their
release and migration records remain available in [release evidence](../release-evidence.md)
and the [0.3.12 release notes](../releases/0.3.12.md). This page is retained as
a historical pointer and does not describe supported behavior in the current
source tree.
