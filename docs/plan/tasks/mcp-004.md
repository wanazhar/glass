# Compact persistent MCP and CLI responses

## Objective

Keep the existing lightweight MCP transport while making agent output compact, deterministic, and free of secret-bearing request logs.

- Use compact JSON serialization on agent-facing hot paths.
- Expose structured action outcomes consistently across CLI and MCP where practical.
