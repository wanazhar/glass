# ir-030-046

Status: complete

## Objective

Expose explicit capability statuses for the browser-free Task Protocol and
experimental draft Web IR surfaces.

## Contract

- Manifest capabilities include `taskProtocol` and `webIr`.
- Both capabilities are enabled for the browser-free contracts.
- Both report `availableUncertified`, distinguishing usable contracts from
  stable cross-platform browser certification.
- Negotiated agreements preserve these statuses without requiring experimental
  opt-in.
- Existing policy-gated and experimental extension statuses remain unchanged.

## Evidence

- Capability tests assert both booleans and status values.
- Negotiation tests request both capabilities and assert their statuses.
- Public MCP documentation explains the status boundary.
