# Bounded semantic region extraction task

- `region.extract` now executes through the revision-guarded Task Protocol
  runtime.
- The task resolves one semantic region by authored scope and reuses the
  existing bounded structured extraction engine.
- Results include source revision, route provenance, truncation metadata, and
  one redacted region record; authored inputs and browser handles are not
  returned.
- CLI `glass task execute` and MCP `executeTask` expose the same behavior.
- Form mutation behavior and confirmation gates are unchanged.
