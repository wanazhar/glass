# Canonical task recovery guidance

## Delivered

- `TaskExecutionResult.retry` now uses the shared typed `RetryGuidance`
  contract instead of an unstructured string.
- Successful, preflight-failed, validation-failed, form-fill, and form-submit
  outcomes expose explicit retry classifications and recommended operations.
- Form submission uncertainty is classified as unsafe until reconciliation;
  callers are directed to `recover_run` rather than blind replay.
- The CLI and MCP task execution surfaces inherit the same serialized recovery
  shape because both use the shared browser session result.

## Verification

- Task unit coverage verifies camelCase recovery serialization.
- All Rust targets pass, including the Linux ARM64 fixture-backed form task
  smoke test.
- No browser identifiers or authored input values are included in the recovery
  guidance.
