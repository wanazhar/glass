# Objective

Define a strict, bounded authored Task Protocol v1 without introducing task
compilation or browser mutation.

# Contract

- Tasks identify a supported family, semantic scope, bounded inputs, limits,
  risk class, ambiguity policy, revision policy, and typed postconditions.
- Authored JSON rejects unknown fields and unsupported task families.
- Scope uses semantic names and entity kinds; selectors, XPath, CDP IDs, and
  raw DOM are not fields in the contract.
- Validation is deterministic, path-aware, and side-effect free.

# Verification

- valid form and extraction task serialization;
- unknown-field, empty-scope, input, and budget rejection tests;
- all-targets tests excluding the known stale daemon test;
- clippy, formatting, and documentation checks.
