# ir-030-049

Status: complete

## Objective

Align offline CLI Task validation and compilation with the canonical protocol
helpers already used by MCP.

## Contract

- CLI Task commands construct versioned `task.validate` and `task.compile`
  requests.
- CLI dispatch uses typed protocol result helpers for validation and compilation.
- Existing bounded CLI output projections remain unchanged: validation emits the
  validation result and compilation emits the plan.
- Neither command starts Chrome or acquires browser state.
- Invalid compilation preserves the typed `TaskCompilation` failure path.

## Evidence

- CLI unit coverage dispatches valid validation and compilation requests through
  canonical operations and asserts invalid compilation returns
  `ProtocolError::TaskCompilation`.
- CLI smoke commands validate and compile a browser-free Task JSON fixture.
- Protocol documentation records shared helper usage and output compatibility.
