# Semantic table and collection records

## Objective

Populate native structured extraction from bounded accessibility evidence so
browser-backed table and collection tasks return semantic values rather than
only interactive target summaries.

## Contract

- Table regions expose bounded row records keyed by bounded column headers.
- Collection regions expose bounded item records with semantic names and
  supported heading, description, and link fields.
- Records contain no selectors, XPath, CDP node IDs, raw DOM, credentials, or
  unbounded page text.
- Empty structured projections remain explicit; task extraction may use the
  existing bounded target projection as a compatibility fallback.
- Source revision, route, limits, truncation, and item provenance remain
  attached to extraction results.

## Delivered

- Added `SemanticStructuredRecord` and bounded table/collection projection
  generation from compact accessibility nodes.
- Added `structuredRecords` to semantic regions and re-exported its type.
- Updated browser-backed `table.extract` and `collection.extract` to consume
  structured records while retaining the bounded target fallback.
- Added deterministic unit coverage for headers, row fields, collection fields,
  and bounded record provenance.
- Added browser smoke coverage for the scoped table and collection tasks.

## Verification

- Semantic and task unit tests pass.
- The complete opt-in browser smoke suite passes: 16 tests.
- Full Rust, formatting, check, Clippy, and repository validation remain
  required before the next release boundary.
