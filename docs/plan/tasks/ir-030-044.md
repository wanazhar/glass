# ir-030-044

Status: complete

## Objective

Extend canonical protocol fixture coverage to bounded typed preflight failures
for browser-free Task Protocol and Web IR validation.

## Contract

- Invalid `task.validate` and `webIr.validate` requests have canonical error
  envelopes with stable operation request IDs.
- Error details identify the typed kind, machine-readable path, and reason.
- Preflight failures explicitly report `mutationPossible: false` and bounded
  retry guidance.
- Existing successful, stale-revision, and compatibility envelopes remain
  unchanged.

## Evidence

- Protocol conformance round-trips every error envelope.
- Conformance asserts task-validation and Web-IR-validation detail kinds and
  paths.
- `GlassError::validate` validates the full error shape and retry guidance.
