# Objective

Provide a reusable Web IR expectation check for emitted and unmatched
relationship-hint diagnostic outcomes.

# Contract

- Existing `DraftFixtureExpectation` remains source-compatible.
- `GlassWebIrDraft::validate_hint_diagnostics_against` validates minimum status
  counts without changing reconciliation behavior.
- Status paths use the serialized camelCase names.
- The expectation check validates the draft before checking diagnostic counts.

# Verification

- `cargo test --lib web_ir --locked`;
- `cargo test --all-targets --locked` excluding the known stale daemon test;
- `cargo clippy --all-targets --all-features --locked -- -D warnings`;
- `cargo fmt --all -- --check`;
- fixture corpus validation.
