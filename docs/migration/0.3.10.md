# Migrate from 0.3.9 to 0.3.10

Update both Rust packages together:

```console
cargo install glass-dev --version 0.3.10 --locked --force
```

Library users should set `glass-browser = "0.3.10"`; the full package retains
the exact dependency `glass-browser =0.3.10`.

## TUI behavior

The 0.3.10 TUI keeps the canonical BrowserWorkspace, Agent conversation,
work-oriented desktop navigation, reduced phone navigation, and semantic-first
projections introduced in 0.3.9. This release makes background agent, browser,
Git, recovery, live-capture, and projection work non-blocking so the terminal
input path stays usable while resident state refreshes.

Per-surface action menus are available through `a`, the unified help cockpit is
available through `?`, and the existing command palette remains the expert
route. Browser semantic selection derives the displayed revision; normal human
click, type, scroll, navigation, recovery, and target flows do not require
manual revision entry. `--tui-live on` enables the bounded ANSI visual fallback
when a native graphics path is unavailable.

## Agent and browser readiness

Pi setup remains explicit and Glass-managed. Use `glass agent doctor`,
`glass agent setup`, and `glass agent status` to inspect Node, the Pi SDK,
authentication, provider, model, and session state. Do not install a global
runtime as a side effect of Cargo installation.

Standalone Browser and embedded App continue to share one BrowserWorkspace
controller and one operation inventory. Browser recovery offers attach,
reconnect, automatic free-port launch, or an explicit port without requiring a
TUI exit.

## Compatibility and safety

There are no intentional public API, MCP, CLI, profile, or workspace-storage
removals. Keep daemon operation IDs and reconcile long-running work after
client reconnects. Browser revisions, mutation confirmation, human takeover,
workspace trust, bounded event history, and semantic invalidation remain
mandatory safety boundaries.

No migration exports secrets, screenshots, DOM, cookies, or prompt content.
