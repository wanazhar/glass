# Revision-guarded semantic tab selection

## Delivered

- `navigation.selectTab` now resolves one unique semantic tab within the
  caller's observed region and clicks it through the revision-guarded action
  runtime.
- Authored tasks require a bounded `inputs.tab` name; non-tab targets and
  ambiguous names fail before dispatch.
- The runtime performs fresh post-action observation and returns typed
  verification and recovery metadata. Any attempted click preserves
  `mutationPossible` when the outcome is indeterminate.
- CLI and MCP task execution inherit the same routing through the shared task
  runtime.

## Verification

- Task Protocol unit coverage validates the required tab input.
- The Linux ARM64 browser smoke fixture includes a semantic tab and exercises
  tab selection before extraction and form operations.
- Full Rust, lint, documentation, package, and release metadata checks remain
  required before publication approval.
