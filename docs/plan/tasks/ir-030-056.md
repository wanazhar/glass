# Public verified Task Protocol execution

## Objective

Expose the browser-backed verified Task Protocol runtime through the CLI
and MCP without creating a second execution path.

## Delivered

- `glass task execute TASK.json --expected-revision REVISION [--confirm]`.
- MCP `executeTask` with the same authored task, revision guard, and explicit
  confirmation contract.
- Both interfaces invoke the canonical `BrowserSession::execute_task`
  dispatcher and return the bounded execution result without serializing
  authored input values.
- Family-specific verification remains behind the shared dispatcher; form fill
  and submit postconditions are evaluated against a fresh scoped observation
  after mutation.

## Safety boundary

All currently supported browser-backed Task Protocol families route through
the shared dispatcher. Unsupported authored families still return a bounded
preflight result, and MCP mutation lease enforcement remains active for
`executeTask`.

## Verification

- CLI help smoke test passed.
- MCP parser and tool inventory tests passed.
- Task runtime unit tests passed.
- Linux ARM64 browser fixture for scoped form execution passed.
