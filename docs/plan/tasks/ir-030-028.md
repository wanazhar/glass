# Objective

Carry the authored task's semantic scope, execution limits, ambiguity policy,
and revision policy into the compiled plan for later guarded execution.

# Contract

- Compiled plans preserve scope, limits, ambiguity, and revision metadata.
- Metadata is copied without input values or browser identifiers.
- Existing plan validation and transport round trips remain valid.
- The plan schema remains additive and browser-free.

# Verification

- Compiler tests assert all guard metadata is propagated.
- Protocol and CLI tests round-trip the enriched plan.
- Full formatting, tests, clippy, documentation, and smoke checks pass.
