# Objective

Carry bounded accessibility ancestry into extraction facts and emit only
relationships supported by an observed region role.

# Contract

- Parent region hints are bounded role labels, not selectors, node IDs, or
  browser references.
- Region hints are populated from accessibility ancestry and form-control
  ancestry only.
- Reconciliation links a child to an observed matching region entity; it never
  invents a target from an unmatched hint.
- Relationship output is deduplicated and deterministically ordered.
- Existing page containment and opaque-boundary semantics remain unchanged.

# Verification

- region relationship reconciliation tests;
- `cargo test --all-targets --locked`;
- `cargo clippy --all-targets --all-features --locked -- -D warnings`;
- `cargo fmt --all -- --check`;
- fixture corpus validation.
