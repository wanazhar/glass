# Objective

Normalize useful bounded phrases locally without embedding an autonomous
planner or external inference service in the runtime.

# Delivered

Added deterministic normalization for pagination, search, filtering, sorting,
open/continue/submit/close phrases, and action-derived fallback purposes.
Vague phrases such as `do it` fail as `unsupportedIntent`; incompatible action
and phrase combinations fail before candidate generation. The canonical
purpose and bounded terms are inspectable by later resolution stages.
