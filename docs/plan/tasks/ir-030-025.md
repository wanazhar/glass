# Objective

Expose browser-free Task Protocol compilation through a deterministic CLI
command for local agents and developers.

# Contract

- `glass task compile TASK.json` reads strict Task Protocol JSON without
  starting Chrome.
- The command prints a typed deterministic execution plan or writes it to an
  explicit output path.
- Input values are never present in the compiled plan.

# Verification

- Clap parsing covers `task compile`;
- CLI smoke execution succeeds with no browser dependency;
- invalid authored tasks fail before session startup;
- all-targets tests excluding the known stale daemon test, clippy, formatting,
  and documentation checks.
