# Objective

Expose deterministic Task Protocol compilation as an MCP tool without starting
or mutating a browser session.

# Contract

- MCP advertises `compileTask` with a strict authored-task object.
- The tool is exempt from mutation leases and browser startup because it only
  validates and compiles a task.
- The result uses the typed `TaskCompileResult` payload inside MCP text content.
- Invalid authored tasks return the standard MCP tool error path.

# Verification

- tool listing includes compileTask;
- valid compileTask calls return a typed deterministic plan with no session;
- parser and lease classification cover the new tool;
- all-targets tests excluding the known stale daemon test, clippy, formatting,
  and documentation checks.
