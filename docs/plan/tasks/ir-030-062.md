# Revision-guarded pagination advance

## Delivered

- `pagination.next` now resolves one unique semantic next control within the
  authored pagination region and clicks it through the guarded action runtime.
- Authored tasks require a bounded `inputs.next` name; ambiguous and
  non-navigation targets fail before dispatch.
- Pagination actions perform fresh post-action observation and preserve typed
  recovery guidance for indeterminate outcomes.
- CLI `glass task execute` and MCP `executeTask` inherit the shared task
  execution route.

- The Linux ARM64 fixture-backed browser smoke executes a bounded pagination
  advance before region extraction and form operations.
