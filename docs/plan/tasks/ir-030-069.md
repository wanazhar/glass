# Field-read authored input validation

## Delivered

- `GlassTask::validate` now requires `inputs.field` for `field.read`.
- Malformed field-read requests fail during transport-independent authored-task
  validation before browser observation or policy checks.
- The runtime preflight guard remains in place for direct Rust callers and
  preserves the same canonical error shape.

## Verification

- Added deterministic Task Protocol unit coverage for the missing field input.
- Linux ARM64 browser smoke continues to verify successful field reads and
  sensitive-value redaction.
