# Contract

The corpus validator must:

- require schema version 1 and a stable corpus identifier;
- require unique fixture and scenario IDs;
- require all roadmap foundation categories to be represented;
- resolve every manifest path relative to the repository root;
- reject missing, empty, oversized, or remote-dependent fixtures;
- bound declared entity and relationship counts;
- preserve explicit coverage and opaque-region declarations;
- produce deterministic output ordering and metrics.

The static baseline is a corpus inventory, not a Web IR runtime result. It must
not claim that extraction or compilation is implemented.
