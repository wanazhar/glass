# Objective

Emit an explicit form-to-field ownership relationship only when bounded form
ancestry evidence supports it.

# Contract

- A `form` parent hint may target an observed `form` entity.
- A form-to-field edge is emitted as `owns`; unmatched hints emit nothing.
- Region and other structural ancestry continue to emit `contains`.
- No selector, node ID, value, or inferred relationship target is introduced.
- Relationship output remains deduplicated and deterministically ordered.

# Verification

- form ownership reconciliation tests;
- `cargo test --all-targets --locked`;
- `cargo clippy --all-targets --all-features --locked -- -D warnings`;
- `cargo fmt --all -- --check`;
- fixture corpus validation.
