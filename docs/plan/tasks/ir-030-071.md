# Bounded pagination collection

## Delivered

- `pagination.collect` now executes a bounded sequence of semantic next
  controls through the guarded runtime.
- Collection obeys the lower of `limits.maxItems` and `limits.maxActions`,
  re-observes after every click, stops when the control disappears or the page
  revision stops changing, and reports a limit alert when bounded work is
  exhausted.
- Failed clicks return indeterminate recovery guidance; blind replay is not
  recommended.
- Authored validation requires `inputs.next` and an explicit region scope.

## Verification

- Fixture-backed Linux ARM64 browser smoke executes two bounded page advances
  and verifies the observe-plus-actions step trace.
- Full Rust, lint, documentation, package, and release metadata checks remain
  required before publication approval.
