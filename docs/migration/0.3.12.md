# Migrate from 0.3.11 to 0.3.12

Status: Historical migration for the published, tagged `v0.3.12` release
(2026-08-22). Its upgrade contract is immutable; post-tag current-source
changes are tracked under [Unreleased](../../CHANGELOG.md#unreleased).

Glass 0.3.12 keeps the 0.3.11 BrowserWorkspace, trust, revision, and
background-work contracts while making the Pi Agent workflow and first-run TUI
experience complete inside `glass`.

## Install the matching package

Install the complete product, which owns both `glass` and
`glass-browser`, from one Cargo package:

```console
cargo install glass-dev --version 0.3.12 --locked --force
```

The focused browser-only product is an alternative owner, not a second
same-root install:

```console
cargo uninstall glass-dev
cargo install glass-browser --version 0.3.12 --locked --force
```

Choose one package owner for a Cargo home. The packages share the
`glass-browser` executable name, so installing both into the same Cargo home
creates an ownership conflict. Library users should set:

```toml
glass-browser = "0.3.12"
```

## Start Pi from the TUI

Run `glass` from the project root. The Agent surface reports the managed Pi
runtime state and exposes these actions:

- `s` or `:agent setup` installs or repairs the pinned SDK runtime.
- `l` or `:agent setup login` opens provider authentication when required.
- `u` or `:agent update` reinstalls the pinned SDK without silently selecting a
  new upstream version.
- `i` opens the composer for the selected resident session; `:agent new`
  starts a separate fresh resident conversation.

Composer turns use the selected resident session. A failed or cancelled turn
can be retried without leaving the TUI; unknown tool calls are rejected once
with evidence and the turn stops instead of looping.

## Browser and workspace behavior

The Agent, Code, App, Terminal, Tasks, Git, Debug, and More surfaces retain the
0.3.11 information architecture. Browser start is headed and profile-backed by
default in the TUI. Use `--incognito --headless` for disposable automation.
When a port is occupied or an attach fails, the in-TUI recovery sheet offers an
attach, free-port launch, or explicit-port retry without losing the workspace.

The App surface `T` picker lists redacted page targets and requires one-use
confirmation before selection. `glass archive-targets` provides a bounded,
redacted JSON inventory for diagnostics and handoff.

## Compatibility and safety

There are no intentional public API removals. Continue to use negotiated
`glass.*` development tools, current workspace generations, and revision-bound
browser actions. Trust is still required before repository-controlled
execution; browser mutations remain fail-closed on stale evidence.

The TypeScript and Python clients remain repository clients. Update their
source-line and handshake metadata with the checkout when embedding them; they
do not install Chrome or Chromium.
