# Objective

Expose bounded standalone validation for browser-free Web IR drafts.

# Contract

- `glass ir validate DRAFT.json` validates the draft without starting Chrome.
- Successful output contains only `valid`, `schemaVersion`, and `revision`.
- Invalid drafts retain path-aware validation errors and produce no success
  payload.

# Verification

- CLI parser coverage covers the validation command.
- CLI smoke coverage confirms the bounded success response.
- Formatting, tests, clippy, documentation, and release checks pass.
