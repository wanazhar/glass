# Bound mutation verification failures and submit evidence

## Delivered

- `navigation.selectTab`, `navigation.openMenu`, `pagination.next`,
  `pagination.collect`, and `form.submit` now convert post-action observation,
  transition-verification, and post-dispatch scope/target reconciliation
  failures into bounded indeterminate results.
- Unified task postcondition re-observation failures preserve the same bounded
  recovery contract instead of leaking raw browser errors.
- Recovery results preserve source/current revisions, mutation possibility,
  failed plan operation, error detail, and unsafe-until-reconciled guidance.
- `NavigationOccurred` postconditions compare the fresh observation revision
  with the task's source revision rather than accepting any nonzero revision.
- Added focused unit coverage for bounded mutation recovery and submit
  postcondition validation.

Full Rust, lint, documentation, package, and release metadata checks remain
required before publication approval.
