# Objective

Carry bounded, explicit relationship hints through extraction and reconciliation
without deriving unsupported semantic categories.

# Contract

- Relationship hints are a closed, serialized extraction enum.
- Extraction sources may omit the hint; omission preserves existing structural
  reconciliation behavior.
- A supplied hint is honored only when its parent role resolves to an observed
  entity.
- Unmatched hints emit no relationship and never create a target entity.
- Hints contain no selectors, CDP node IDs, URLs, credentials, or form values.

# Verification

- explicit hint reconciliation tests;
- `cargo test --all-targets --locked`;
- `cargo clippy --all-targets --all-features --locked -- -D warnings`;
- `cargo fmt --all -- --check`;
- fixture corpus validation.
