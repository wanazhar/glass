# Objective

Extend the existing `KnowledgeRecord` and `KnowledgeStore` contracts so verified memory can be scoped to the surface and backend that produced it, classified for portability, and inspected for how it influenced a compiler advisory. Preserve the current rule that knowledge never authorizes mutation and fresh Web IR remains authoritative.

# Contract

Add bounded, serde-stable metadata for:

- source surface kind and understanding/coverage level;
- source backend and capability profile;
- portability classification (`semanticPortable`, `surfacePortable`, `backendCapabilityDependent`, `backendSpecific`, `browserSpecific`, `nonPortable`);
- memory influence (`none`, `rankingOnly`, `templateSuggested`, `verificationSuggested`, `recoverySuggested`, `identityContinuitySuggested`);
- explainable retrieval signals and current-validation status.

Unknown values must fail closed. Sensitive values remain rejected/redacted. Existing snapshots must remain readable through an explicit additive migration/default path already permitted by the knowledge contract. A record cannot be promoted or used as executable evidence without current validation.

# Verification

Run focused knowledge unit tests and a targeted serialization/migration test. Do not run formatters, linters, or project-wide test suites. Commit with a conventional `feat(memory): ...` or `fix(memory): ...` message before handoff.
