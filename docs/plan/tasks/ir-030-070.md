# Browser task region scope validation

## Delivered

- Authored validation now requires `scope.regionName` for browser-backed form,
  field, tab, pagination, table, collection, and region extraction tasks.
- Runtime scope errors now use task-family-neutral wording and preserve the
  same fail-closed behavior for direct Rust callers.
- Protocol fixtures now carry the explicit region required by `field.read`.

## Verification

- Added deterministic validation coverage for missing browser task region
  scopes.
- Full Rust, lint, documentation, package, and release metadata checks remain
  required before publication approval.
