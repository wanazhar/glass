# Browser-free MCP Web IR diff and continuity

## Objective

Expose existing deterministic Web IR revision diff and entity continuity
classification through bounded MCP operations without starting Chrome or
acquiring a mutation lease.

## Contract

- `diffWebIr` accepts two validated draft objects and returns revision metadata,
  entity and relationship change counts, and bounded coverage/diagnostic change
  flags. It does not return entity payloads, relationships, or page content.
- `continuityWebIr` accepts two validated draft objects and one source entity ID,
  then returns the existing unchanged/changed/rebound/removed/ambiguous
  classification with a bounded reason and optional current ID.
- Both operations reject invalid graph input with the existing typed
  `webIrValidation` error shape.

## Verification

MCP regression tests exercise both operations with no browser session, protocol
conformance includes both tool names, and the full repository checks remain
required before the local commit.
