# Objective

Extend the versioned Web IR fixture inventory with optional relationship-hint
diagnostic expectations without claiming runtime extraction coverage.

# Contract

- `expectedHintDiagnostics` is optional per fixture and defaults to empty.
- Each entry contains a unique camelCase `status` and bounded non-negative
  `count`.
- Allowed statuses are `validated`, `emitted`, and `unmatchedParent`.
- The corpus remains inventory-only; metadata does not assert that HTML
  extraction currently produces explicit hints.

# Verification

- `python3 scripts/check-web-ir-corpus.py`;
- `cargo test --test web_ir_corpus --locked`;
- `cargo test --all-targets --locked` excluding the known stale daemon test;
- `cargo fmt --all -- --check`;
- `cargo clippy --all-targets --all-features --locked -- -D warnings`.
