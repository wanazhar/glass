# ir-030-051

Status: complete

## Objective

Complete canonical preflight error coverage for all browser-free Web IR
operations.

## Contract

- Invalid `webIr.validate`, `webIr.diff`, and `webIr.continuity` requests use
  `webIr.invalid` preflight envelopes.
- Validation details are typed as `webIrValidation` with bounded paths and
  reasons.
- Invalid Web IR requests never imply browser access or mutation.
- Success response contracts remain unchanged.

## Evidence

- Golden protocol requests and responses cover invalid validation, diff, and
  continuity operations.
- Protocol conformance dispatches each invalid request through its typed result
  helper and asserts `ProtocolError::WebIrValidation`.
- Response conformance checks the shared error code, kind, and path.
