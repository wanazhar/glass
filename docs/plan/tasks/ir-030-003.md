# Objective

Make extraction completeness and evidence quality explicit before reconciliation
or Web IR entities are introduced.

# Context

- `issue://wanazhar/glass/30`
- `docs/plan/analysis/semantic-execution-030.md`
- `src/extraction.rs`

# Path

- `src/extraction.rs`
- `docs/plan/README.md`

# Contract

Evidence output must expose:

- explainable quality classes: confirmed, strong, partial, inferred,
  conflicted, and opaque;
- structural and semantic coverage classes;
- observed interactive count;
- opaque-region count;
- bounded coverage reasons;
- truncation and missing-source state without conflating either with absence.

Facts must carry their quality class. The output remains evidence, not a Web IR
entity graph, and must not authorize actions or infer unsupported structure.
