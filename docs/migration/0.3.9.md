# Migrate from 0.3.5 to 0.3.9

Skip the unpublished 0.3.6 through 0.3.8 tags and update directly:

```console
cargo install glass-dev --version 0.3.9 --locked --force
```

Library users should set `glass-browser = "0.3.9"`; the full package retains
the exact dependency `glass-browser =0.3.9`.

The product and automation changes are the canonical BrowserWorkspace, rebuilt
Agent/Code/App desktop and phone shells, managed Pi lifecycle, stable daemon
operations, inferred verification, revision-bound actions, and explicit human
takeover/reconciliation described in the 0.3.6 candidate guide. Version 0.3.9
also keeps standalone TUI browser startup off the input loop, synchronizes the
Windows named-pipe integration fixture with the recoverable-operation protocol,
and makes native concurrency certification scheduler-safe.

No migration exports secrets, screenshots, DOM, cookies, or prompt content.
