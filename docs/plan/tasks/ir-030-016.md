# Objective

Extend custom form-control hint production to common ARIA widget roles while
preserving bounded source semantics.

# Contract

- Forms extraction recognizes checkbox, combobox, listbox, radio, slider,
  spinbutton, switch, and textbox roles.
- All non-textbox roles in that set under a bounded `form` ancestor emit a
  `controls` hint.
- Textbox roles retain ownership inference without an explicit hint.
- Existing source, budget, and redaction boundaries remain unchanged.

# Verification

- extraction tests for extended roles and plain text controls;
- all-targets tests excluding the known stale daemon test;
- clippy, formatting, docs, and fixture corpus validation.
