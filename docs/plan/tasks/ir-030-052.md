# ir-030-052

Status: complete

## Objective

Expose the bounded canonical Web IR diff projection through an explicit offline
CLI mode without changing the detailed diagnostic default.

## Contract

- `glass ir diff before.json after.json` keeps the detailed diff output.
- `glass ir diff before.json after.json --summary` emits `WebIrDiffResult`.
- Both modes validate drafts locally and never start Chrome.
- The summary remains bounded and excludes entity or page content.

## Evidence

- CLI parser coverage verifies both default and `--summary` forms.
- Runner coverage verifies the canonical summary projection for a deterministic
  self-diff.
- CLI smoke coverage and repository gates validate the end-to-end command.
