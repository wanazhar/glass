# Verified semantic tab selection

## Delivered

- `navigation.selectTab` now requires the selected semantic tab to expose
  `aria-selected="true"` after the revision-guarded click.
- ARIA state verification polls within the task timeout, allowing delayed
  application state while preserving bounded execution.
- Unverified tab clicks return `indeterminate` recovery guidance instead of a
  false success result.
- Added delayed-success and no-op Linux ARM64 browser smoke coverage.
