# ir-030-048

Status: complete

## Objective

Extend canonical protocol conformance to cover deterministic Task compilation
failures, not only successful plans and Task validation failures.

## Contract

- Invalid `task.compile` requests remain browser-free preflight failures.
- The canonical envelope uses `task.invalid`, `phase: preflight`, and
  `mutationPossible: false`.
- Error details use `kind: taskCompilation` with bounded `path` and `reason`.
- Typed protocol helpers decode the request and return
  `ProtocolError::TaskCompilation`.

## Evidence

- The protocol golden fixture contains invalid `task.compile` request and
  response envelopes.
- Protocol conformance dispatches the request through
  `compile_task_result` and asserts the typed error variant.
- Response conformance checks the error code, kind, and path.
