# Objective

Classify whether a draft entity remains safe to use across two validated Web IR
revisions.

# Contract

- Continuity statuses are `unchanged`, `changed`, `rebound`, `removed`, and
  `ambiguous`.
- Same semantic kind, role, and name permit a bounded semantic-key lookup only
  when the revision-local ID disappeared.
- A changed entity with the same ID is stale, not silently rebound.
- Multiple semantic-key candidates are ambiguous and fail closed.
- Missing identity fields prevent semantic rebinding rather than authorizing a
  guess.

# Verification

- continuity tests for unchanged, changed, removed, rebound, and ambiguous
  targets;
- all-targets tests excluding the known stale daemon test;
- clippy, formatting, docs, and corpus validation.
