Implemented an explicit execution request containing a candidate ID and a
bounded value for type/select actions. The session re-observes and resolves on
the current revision, requires the caller-selected candidate to remain
eligible, and dispatches supported actions through the existing revision-aware
action methods. Results keep resolution evidence, resolution ID, action
evidence, and action execution ID separate. Unsupported action classes fail
validation before dispatch.
