# Objective

Expose deterministic intent resolution without creating a second action
execution path.

# Delivered

Added `BrowserSession::resolve_intent` and the `glass resolve-intent` JSON
command. Both return candidates and policy outcomes only; execution remains
with the existing guarded action APIs. Invalid requests fail before browser
resolution and current semantic revisions remain authoritative.
