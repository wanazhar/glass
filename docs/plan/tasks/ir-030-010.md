# Objective

Reject relationship hints that are not justified by their selected evidence
source or that lack a bounded parent role.

# Contract

- Every relationship hint must include a bounded parent role.
- Each evidence source has an explicit conservative hint allowlist.
- Invalid hints fail before draft reconciliation with a stable field path.
- Valid hints preserve the existing deterministic relationship behavior.
- No source validation creates entities, relationships, selectors, node IDs, or
  browser actions.

# Verification

- source allowlist unit tests;
- draft reconciliation rejection tests;
- `cargo test --all-targets --locked`;
- `cargo clippy --all-targets --all-features --locked -- -D warnings`;
- `cargo fmt --all -- --check`;
- fixture corpus validation.
