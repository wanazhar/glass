# Objective

Represent declared opaque coverage explicitly in the draft Web IR graph and
strengthen graph invariants before adding richer relationship evidence.

# Context

- `issue://wanazhar/glass/30`

- `src/web_ir.rs`

# Contract

- Each declared opaque coverage unit becomes an explicit `opaqueRegion` entity.
- Opaque entities never claim action capability or confirmed child coverage.
- Opaque entities may have no source provenance when they represent a coverage
  boundary rather than a positive browser fact.
- Every opaque entity is contained by the page entity.
- Draft validation requires exactly one page entity and rejects dangling or
  self-referential relationships.
